# LinkedIn channel — message format rules

How a LinkedIn touch differs from a cold email. This card is force-included by the LinkedIn
message drafter (the same way product_positioning_us is force-included everywhere).
Keywords: linkedin, connection request, invite, message format, dm, follow-up, channel.

## The ladder (what the lead experiences)
Profile view → like on a recent post → **connection request WITHOUT a note** → they accept →
message #1 → 3–4 days of silence → one follow-up. A reply at any point hands the thread to a human.

**Why no note on the invite:** our own live A/B (2,433 invites, Aug 2026): no-note invites were
accepted at **43%**, invites with a pitch note at **12%**. The note costs 3.5× the acceptance.

## Message #1 — right after they accept
- **Under 40 words.** This is a chat message, not a letter. No subject line exists.
- Context is "we just connected": thank briefly, then ONE question about how they handle
  sourcing/tail spend today. A question, not a pitch.
- **No links, no attachments, no pricing, no client names, no numbers.** Materials go in replies only.
- **No signature and no personal credibility lines** ("ex-McKinsey", "I founded…"): the same template
  is sent from several different profiles — the sending profile IS the identity and the credibility.
- {{first_name}} and {{company_name}} are available. {{unique_detail_short}} is NOT allowed here.

## Follow-up — after 3–4 days of silence
- **Under 60 words.** One new angle, not a repeat of message #1.
- {{unique_detail_short}} is allowed here, as its own standalone sentence.
- Still no links and no pricing. A soft close is fine ("no worries if not relevant").

## Tone
Peer to peer, not vendor to prospect. Shorter sentences than email. Contractions are normal.
The bar: if the lead pasted the message to a colleague, it should read like a person typing,
not a sequence firing.
